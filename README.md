# ai-agent-ide-plugins

个人维护的 AI Agent IDE 插件集合。当前用 CodeBuddy 开发测试，但不限定特定 IDE——后续可能扩展到其他 AI Agent 平台。

## 包含的插件

| 插件 | 说明 |
|------|------|
| [my-superpowers](./my-superpowers/) | 精简版 superpowers 技能集，专为 CodeBuddy 适配 |

## 用法

进入对应插件目录的 README 查看安装和使用说明。每个插件自带其目标平台的清单文件（如 `.codebuddy-plugin/plugin.json`），按对应平台的方式注册即可。
